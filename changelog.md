### 2.2.16

1. Invalid MultiWord counts and custom regular expressions are now reported before settings are saved, keeping the dialog open and focusing the field that needs correction.
2. Fixed word navigation and selection when the Bulky word separator list is empty.
3. Shift+Left/Right now uses the application's normal selection behavior when WordNav word selection is disabled or the application is excluded.
4. Application exclusions now correctly handle spaces around individual names in comma-separated lists.
5. Updated the build tooling to the current NVDA AddonTemplate.
